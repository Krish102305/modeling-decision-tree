# Modeling - decision tree: clinic no-shows (overbook or hold)

Code that reproduces every number in the write-up for this assignment.

- `decision_tree.py`: the full analysis. Run `python decision_tree.py` from this folder.
- `clinic_appointments.csv`: the CSV data provided with the assignment
- `decision_tree_output.txt`: the script's printed output
- `tree.png`: figure produced by the script

Requires: pandas, numpy, scikit-learn, matplotlib. Random seed fixed at 42.
